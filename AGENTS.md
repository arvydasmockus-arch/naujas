# Flowly – AI taisyklės

Šios taisyklės skirtos AI asistentui, dirbančiam su Flowly projektu.

## Skills

- Dirbdamas šiame projekte nenaudok ir neskaityk jokių lokaliai įdiegtų skills.
- Vadovaukis šiame faile pateiktomis projekto taisyklėmis.

## Technologijos

- Naudok React + Vite.
- Rašyk JavaScript ir JSX.
- Nenaudok TypeScript.
- Nenaudok Tailwind CSS ar CSS Modules.
- Kiekvienam komponentui naudok atskirą `.jsx` ir `.css` failą.
- Komponentus laikyk `src/` kataloge.

## Kodo keitimas

- Prieš keisdamas failą, remkis naujausia jo versija.
- Neišgalvok neegzistuojančių funkcijų ar projekto logikos.
- Jei trūksta reikalingo failo turinio – paprašyk jo.
- Keisdamas failą pateik VISĄ atnaujintą failą, ne tik pakeistą fragmentą.
- Nedaryk nereikalingų kitų failų pakeitimų.
- Išlaikyk esamą projekto struktūrą.

## React

- Naudok funkcinius komponentus.
- State valdymui naudok React hooks, pvz. `useState`.
- Komponentus skaidyk tik tada, kai tai pagerina kodo aiškumą.
- Venk nereikalingų bibliotekų ir dependencies.
- Rinkis paprastą sprendimą prieš sudėtingą architektūrą.

## Dizainas

Išlaikyk dabartinį Flowly stilių:

- tamsi tema;
- violetinis pagrindinis akcentas;
- tamsios kortelės;
- subtilūs borderiai;
- šviesus pagrindinis tekstas;
- pilkas antrinis tekstas;
- apvalinti kampai;
- minimalistinis modernus UI;
- responsive dizainas.

Nekeisk bendros dizaino krypties be aiškaus prašymo.

## UI tekstas

- Naudok lietuvių kalbą.
- Tekstas turi būti trumpas ir aiškus.
- Nekeičiant funkcionalumo nekeisk jau naudojamų terminų be priežasties.

## Prieš pateikiant kodą

Patikrink:

1. Ar kodas suderinamas su dabartiniu projektu.
2. Ar nėra nereikalingų dependencies.
3. Ar nepažeistas esamas funkcionalumas.
4. Ar UI išlieka responsive.
5. Ar pateikti visi failai, kuriuos reikia pakeisti.

## Atsakymo formatas

Kai siūlai pakeitimus:

- trumpai paaiškink, kas keičiama;
- nurodyk tikslų failo kelią, pvz. `src/App.jsx`;
- pateik visą failo kodą;
- aiškiai parašyk, ar failą reikia sukurti, ar pakeisti;
- pabaigoje trumpai parašyk, kaip patikrinti rezultatą.
